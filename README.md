# Stick Fight: The Game — Decompilation

Uma decompilação do jogo **Stick Fight: The Game**.

## Requisitos

* Unity 2017.4.40f1
* Git
* Library do projeto (Download: https://www.mediafire.com/file/kk4h0qkwwp5qbif/LibraryStickFightDecomp.zip/file)

Só precisa renomear de "LibraryStickFightDecomp" para "Library".

## Créditos

* **Landfall Games** — por criar um jogo incrível que fez parte da minha infância ❤️.
* **Eu** — pela decompilação do jogo deles :P

## Sobre

O projeto original utilizava Unity 5.6.x mas eu portei para Unity 2017.4.40f1 porque quis evitar problemas com uma versão da unity tão antiga como essa.

Quase 100% do jogo está funcionando. A principal exceção é o **Steamworks**, que atualmente funciona a base de **stubs**.

Este projeto tem como objetivo preservar e estudar o funcionamento do jogo através de sua decompilação.
